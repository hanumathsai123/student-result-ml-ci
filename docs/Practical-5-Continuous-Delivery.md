# Practical-5: Continuous Delivery of an ML Prediction Application using GitHub Actions

Continuation of Practical-4: Preserving ML Artifacts.

## Objective
Extend the Student Result Prediction ML CI workflow so a validated model is combined with a Flask prediction application, tested, packaged, and preserved as a release candidate ready for deployment. This is Continuous Delivery, not production deployment.

## Prerequisites
The repository should already train and validate the model, run automated ML tests, and preserve model artifacts through `.github/workflows/ml-ci.yml`.

## Implementation

### 1. Add Flask dependency
Add `flask` to `requirements.txt`, alongside the existing packages:
```text
numpy
pandas
scikit-learn
joblib
flask
```

### 2. Create `app.py`
```python
from pathlib import Path

import joblib
import pandas as pd
from flask import Flask, jsonify, request

app = Flask(__name__)
MODEL_PATH = Path("student_result_model.pkl")
FEATURES = ["attendance", "internal_marks", "assignment_marks", "previous_score"]

def load_model():
    if not MODEL_PATH.exists():
        raise FileNotFoundError("student_result_model.pkl was not found. Run the training pipeline first.")
    return joblib.load(MODEL_PATH)

@app.get("/")
def health_check():
    return jsonify({"status": "ok", "service": "student-result-prediction"})

@app.post("/predict")
def predict():
    data = request.get_json(silent=True)
    if not data:
        return jsonify({"error": "JSON request body is required"}), 400
    missing_fields = [feature for feature in FEATURES if feature not in data]
    if missing_fields:
        return jsonify({"error": "Missing required fields", "missing_fields": missing_fields}), 400
    sample = pd.DataFrame([{feature: data[feature] for feature in FEATURES}])
    bundle = load_model()
    scaled = bundle["scaler"].transform(sample)
    prediction_code = int(bundle["model"].predict(scaled)[0])
    return jsonify({"prediction": "PASS" if prediction_code == 1 else "FAIL",
                    "prediction_code": prediction_code})

if __name__ == "__main__":
    app.run(host="0.0.0.0", port=5000)
```

Note: this model file is a bundle containing `scaler` and `model`, generated by the repository's current `train_model.py`.

### 3. Create `test_app.py`
```python
import unittest
from app import app

class TestPredictionApplication(unittest.TestCase):
    def setUp(self):
        self.client = app.test_client()

    def test_health_endpoint(self):
        response = self.client.get("/")
        self.assertEqual(response.status_code, 200)
        self.assertEqual(response.get_json()["status"], "ok")

    def test_high_performance_prediction(self):
        response = self.client.post("/predict", json={
            "attendance": 95, "internal_marks": 95,
            "assignment_marks": 95, "previous_score": 95
        })
        self.assertEqual(response.status_code, 200)
        self.assertEqual(response.get_json()["prediction"], "PASS")

    def test_low_performance_prediction(self):
        response = self.client.post("/predict", json={
            "attendance": 50, "internal_marks": 40,
            "assignment_marks": 40, "previous_score": 40
        })
        self.assertEqual(response.status_code, 200)
        self.assertEqual(response.get_json()["prediction"], "FAIL")

    def test_missing_field_validation(self):
        response = self.client.post("/predict", json={"attendance": 90, "internal_marks": 85})
        self.assertEqual(response.status_code, 400)
        self.assertIn("missing_fields", response.get_json())

if __name__ == "__main__":
    unittest.main()
```

### 4. Update GitHub Actions workflow
Add application tests after model tests and create the release candidate after all tests pass. Keep the existing training, quality gate, and artifact steps; ensure Flask is installed via requirements.txt.

```yaml
      - name: Run prediction application tests
        run: python -m unittest test_app.py -v

      - name: Prepare release candidate
        run: |
          mkdir -p release_candidate
          cp app.py release_candidate/
          cp student_result_model.pkl release_candidate/
          cp metrics.json release_candidate/
          cp requirements.txt release_candidate/
          printf "Student Result Prediction ML Application\nRun: python app.py\nEndpoint: POST /predict\n" > release_candidate/DEPLOYMENT.txt

      - name: Upload release candidate
        uses: actions/upload-artifact@v7
        with:
          name: student-result-ml-release
          path: release_candidate/
          if-no-files-found: error
          retention-days: 7
```

### 5. Verify
Commit the dependency, application, tests, and workflow changes. Open Actions and confirm the run trains the model, passes the quality gate, runs ML and API tests, and uploads `student-result-ml-release`.

**Expected artifact:** `app.py`, `student_result_model.pkl`, `metrics.json`, `requirements.txt`, and `DEPLOYMENT.txt`.
